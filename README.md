# Student Placement Prediction System

A Machine Learning-based web application that predicts student placement outcomes based on academic performance and other important factors.

## About the Project

The Student Placement Prediction System is an academic project developed to help students understand their placement possibilities based on various parameters such as CGPA, internship experience, projects, backlogs, and communication skills.

The application uses Machine Learning and Flask to generate placement predictions through a user-friendly web interface.

## Features

- Student login interface
- Placement prediction system
- Input-based prediction
- Machine Learning model integration
- Interactive and user-friendly interface
- Prediction results displayed on the web application

## Technologies Used

- **Programming Language:** Python
- **Backend Framework:** Flask
- **Machine Learning:** Scikit-learn
- **Data Analysis:** Pandas, NumPy
- **Frontend:** HTML, CSS, JavaScript

## Input Parameters

The system considers the following parameters:

1. CGPA
2. Internship Experience
3. Number of Projects
4. Backlogs
5. Communication Skills

## How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/PrathamPaswan-01/student-placement-prediction-system.git
   ```

2. Navigate to the project folder:

   ```bash
   cd student-placement-prediction-system
   ```

3. Install the required dependencies:

   ```bash
   pip install flask pandas numpy scikit-learn
   ```

4. Run the Flask application:

   ```bash
   python app.py
   ```

5. Open your browser and visit:

   ```text
   http://127.0.0.1:5000
   ```
